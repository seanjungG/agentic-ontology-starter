# 위약금 면제 특례 가이드

> 문서 번호: GUIDE-SUB-03 · 적용일: 2026-01-01 · 대상: 매장·고객센터 상담원 · 비식별 실습용 합성 문서

## 1. 시니어·복지 면제

1. 만 65세 이상 시니어 또는 복지 대상으로 등록된 고객(시스템 복지 상태값 SENIOR_EXEMPT)이 **시니어·복지 전용 요금제**로 바꾸는 경우, 180일 안이라도 차액정산금을 **전액 면제(0원)**한다.
2. 시니어·복지 전용 요금제가 아닌 일반 요금제로 낮추는 경우에는 면제되지 않는다.
3. 시니어·복지 전용 요금제는 요금제 테이블의 요금제 구분(tier_category) 값이 SENIOR_WELFARE인 요금제다.

## 2. 군 입대 일시정지

1. 군 입대로 회선을 일시정지한 고객(시스템 복지 상태값 MILITARY_PAUSE_ELIGIBLE 확인 후 정지 처리)은 복무 기간 동안 180일 의무유지 기간 계산이 **멈춘다**.
2. 일시정지 자체로는 위약금이 생기지 않는다. 전역 후 회선을 다시 쓰면 남은 의무유지 기간을 이어서 채운다.

## 3. 면제 확인 절차

- 상담원은 면제를 안내하기 전에 고객의 복지 상태값과 바꿀 요금제의 구분을 반드시 확인한다.
- 면제 사유가 확인되지 않으면 일반 차액정산 규칙(GUIDE-SUB-02)을 적용한다.
